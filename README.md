# Moog's Voyager Structures Integrated

An addon for [Moog's Voyager Structures](https://www.curseforge.com/minecraft/mc-mods/moogs-voyager-structures) that replaces the vanilla-block structures with versions integrating blocks and items from [Supplementaries](https://www.curseforge.com/minecraft/mc-mods/supplementaries) and [Amendments](https://www.curseforge.com/minecraft/mc-mods/amendments).

## Requirements

- [Moog's Structure Lib](https://www.curseforge.com/minecraft/mc-mods/moogs-structure-lib)
- [Supplementaries](https://www.curseforge.com/minecraft/mc-mods/supplementaries)
- [Amendments](https://www.curseforge.com/minecraft/mc-mods/amendments)

## Installation

1. Install the required mods listed above
2. Download the correct version for your Minecraft version
3. Place in your mods folder

This mod uses the `mvsintegrated` mod ID and coexists alongside the original Moog's Voyager Structures (`mvs`).
